# 🛒 Sportsware E-Commerce

Proyecto de tienda virtual desarrollado como práctica de desarrollo web utilizando tecnologías básicas del entorno Frontend y Backend.

## 📌 Descripción

Sportsware E-Commerce es un sistema web básico de comercio electrónico orientado a la venta de ropa deportiva.  
El proyecto implementa funcionalidades esenciales de una tienda online utilizando tecnologías web fundamentales como HTML, CSS, JavaScript y MySQL.

El objetivo principal del proyecto es fortalecer conocimientos en:

- Desarrollo Frontend
- Manipulación del DOM
- Diseño responsivo
- Interacción dinámica con JavaScript
- Gestión de bases de datos MySQL
- Estructuración de proyectos web

# 🖥️ Instalación y Ejecución

## 1. Clonar el repositorio

```bash
git clone https://github.com/Trackerlxl/Sportsware-E-Commerce-.git
```

---

## 2. Mover el proyecto a XAMPP

Ubicar el proyecto dentro de:

```bash
C:\xampp\htdocs\
```

---

## 3. Iniciar Apache y MySQL

Desde el panel de control de XAMPP iniciar:

- Apache
- MySQL

---

## 4. Importar la base de datos

1. Abrir phpMyAdmin
2. Crear una base de datos
3. Importar el archivo `.sql` del proyecto

---

## 5. Ejecutar el proyecto

Abrir en el navegador:

```bash
http://localhost/Sportsware
```
